## Project Setup

I created and configured this project using the following commands:

**1. Initialize npm project**
```bash
npm init -y
```

**2. Initialize TypeScript configuration**
```bash
tsc --init
```

**3. Install tsx as a development dependency**
```bash
npm install -D tsx
```

## How to Run

To run the assignment and watch for file changes, use:

```bash
npx tsx watch src/solutions.ts
```

This command executes the TypeScript file and automatically reruns it when changes are detected.
